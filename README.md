# Catálogo de produtos ASETECH

Feed de produtos digitais (RSS 2.0, padrão Google/Meta) gerado a partir de https://www.asetech.com.br.

- URL do feed: https://raw.githubusercontent.com/asetechsolucoes/asetech-catalogo/main/produtos.xml
- Atualização automática: 2x por dia via GitHub Actions
- Gerar manualmente: `python3 gerar_feed.py produtos.xml`

| Rótulo | Valores |
|---|---|
| custom_label_0 | `b2c` / `b2b` |
| custom_label_1 | `ate-300`, `300-700`, `700-1500`, `1500-mais` |
| custom_label_2 | marca |
| custom_label_3 | `atual` / `legado` |
| custom_label_4 | linha: `m365`, `office`, `windows`, `antivirus`, `combo`, `servidor`, `design`, `certificado` |
